# 文件上传
1. 前端读取本地文件，并做切片处理（Blog 对象的 slice 方法），Blog 是浏览器环境下的数据格式，node 没有
2. 前端将切片处理成 FormData 对象，并做好标记、
3. 前端将 FormData 对象发送给后端

4. 后端接收前端的 FormData 对象（借助插件 mutiipatry 解析 from 表单数据）
5. 后端将收到的切片文件存储到本地
6. 后端合并切片文件
 - 循环创建连续的可写流空间
 - 将切片文件读成流类型，并写入流空间 


# 文件断点续传
1. 当文件片段上传到一半时，暂停传输，之后又继续传输
2. 当前端点击继续传输按钮后，先发一个校验请求来获取后端已经接收到的文件的片段信息（文件名字和编号）
3. 前端过滤掉已经传输完毕的片段，继续传输剩下的片段
