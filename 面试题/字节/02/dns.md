# DNS 解析
1. 浏览器向本地 DNS 服务器发送域名解析请求  （本地缓存没有记录）
2. 本地 DNS 服务器向根 DNS 服务器发送域名解析请求 （根服务器返回顶级域服务器地址）
3. 本地 DNS 服务器向顶级域服务器发送域名解析请求 （顶级域服务器返回权威域名服务器地址）
4. 本地 DNS 服务器向权威域名服务器发送域名解析请求 （权威域名服务器返回域名对应的 IP 
5. 本地 DNS 服务器将域名对应的 IP 地址缓存起来，以便下次查询
6. 同时，本地 DNS 服务器还会将域名对应的 IP 地址返回给浏览器


# TCP 三次握手
1. 客户端向服务器发送建立连接请求，并进入 SYN_SENT 状态
2. 服务器接收到客户端的连接报文后，向客户端发送同意报文，并进入 SYN_RECV 状态
3. 客户端接收到服务器的同意报文后，向服务器发送确认报文，并进入 ESTABLISHED 状态
