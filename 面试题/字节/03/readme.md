# post 和 get
1. get 参数放在 url 中，post 参数放在 body 中
2. get 只能获取数据，post 可以获取数据和修改数据
3. post 支持更多类型的编码
4. get 有大小限制，post 没有大小限制
5. get 是幂等的，post 不是幂等的
6. get 是安全的，post 不是安全的
7. get 可以被缓存，有历史记录，post 不能被缓存

# 菜单权限控制
1. 前后端不分离（ssr）：数据库中记录账号的权限，根据登录账号的查询权限，然后返回 html
2. 前后端分离（csr）：根据接口返回数据，前端根据权限来控制跳转哪一个页面，配合路由守卫来控制页面的展示
3. 前后端分离：数据库中记录账号的权限，根据登录账号的查询权限，返回该权限能访问的菜单列表数据
