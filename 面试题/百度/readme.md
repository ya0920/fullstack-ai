# 3.vue3和vue2的区别，vue和react的区别
  - 1. vue3 引入 Composition API， 更贴近原生 js，更灵活，代码的可读性更高
  - 2. vue3 源码用 ts 重写，所以在 vue 开发中使用 ts 更方便
  - 3. 速度更快 （1. 模板编译更加了静态节点缓存， diff 算法优化只比较动态节点， 增加了快速 diff 的方式。 2. 事件缓存） 
  - 4. 体积更小  (打包的项目代码体积更小： 因为Composition API 的语法 + 构建工具的 tree-shaking 功能 实现没有使用的函数不会打包进去)

# 11.协商缓存 LastModified 和 Etag 的区别
 - LastModified：通过文件的最后一次修改时间来判断是否被跟新这是不严谨的，一旦修改后又删除修改，依然会认为文件更新过。
 - Etag：通过文件的内容生成一个唯一的标识，只要内容不变，Etag就不会改变。 （文件指纹）
# 12.大文件上传怎么做的、断点续传
 - 1. 前端读取到文件，转化为 Blob 对象
 - 2. Blob对象进行切片 （slice）
 - 3. 将 blob 对象转换成 FormData 对象，然后通过 ajax 发送请求
 - 4. 服务端接收到请求，将文件保存到本地
 - 5. 客户端发送合并请求，服务端接收到请求，将文件合并
