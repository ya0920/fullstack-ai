# 调用栈

v8引擎用来管理函数之间的调用关系的一种结构

1. 编译永远发生在执行的前一刻
2. 全局和函数体的编译会生成执行上下文存入调用栈
3. 当一个函数执行完毕后，他的执行上下文就会被销毁（出栈）

ps.一个栈几十kb

# 编译的过程
1. 创建执行上下文对象
2. 找形参和变量声明，将形参和声明的变量名作为key值为undifined
3. 统一形参和实参的值（ 全局没有该步骤 ）
3. 在作用域里找函数声明，将函数名作为key，值为函数体
